# Mauricio Felippe &mdash; Official Website

Personal website and portfolio of **Mauricio Felippe** (Sandbox Workspace Productions).

Showcasing independent video games (*Back to Belt*, *Cosmic Horizon*, *Curses 'N Abominations*), short films (*Sob Sonhos*, *A chama vazia*, *Ad Hoc*, *Echo*, *Paola*), and devlogs.

Hosted on [GitHub Pages](https://mauriciofelippe.github.io) with custom domain support.

## Project Structure

```text
├── _includes/       # Reusable layout fragments (header, footer, nav)
├── _layouts/        # Jekyll layouts (default, post)
├── _posts/          # Devlog posts written in Markdown
├── assets/
│   ├── css/         # Modern dark portfolio stylesheet
│   ├── img/         # Game art, box art, concept art & media
│   └── js/          # Mobile navigation toggle & image lightbox modal
├── games/           # Video game project showcases
├── shorts/          # Cinematic short movies & embedded players
├── blog/            # Devlog index and archives
├── about/           # Bio, studio information & contact details
├── _config.yml      # Jekyll configuration
└── CNAME            # Custom domain mapping
```
