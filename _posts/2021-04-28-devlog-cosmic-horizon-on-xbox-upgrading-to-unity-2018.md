Today I started upgrading **[Cosmic Horizon](/games/cosmic-horizon/)** for **XBOX** from Unity 5 to Unity 2018.

Following the Unity documentation, the recommended process is to create a complete project backup and open it directly within the newer Unity version.

![Upgrading Cosmic Horizon to Unity 2018]({{ '/assets/img/image.png' | relative_url }})

Upgrading an engine version on an active console target always brings unexpected shader, lighting, and API changes, but taking it step-by-step makes the transition smooth.
